# Windmill MIS Dashboard

## Overview

This Power BI dashboard provides insights into windmill power generation performance. It enables users to monitor energy production, analyze trends, compare locations, and evaluate operational efficiency through interactive visualizations.

## Dashboard Features

* Total Generation Overview
* Monthly Generation Trends
* Financial Year Performance Analysis
* Location-wise Generation Comparison
* Capacity-wise Generation Analysis
* Windmill Manufacturer Contribution
* Interactive Filters and Slicers
* Executive Summary Metrics

## Tools Used

* Microsoft Power BI
* Power Query
* DAX
* Excel Dataset

## Key Metrics

* Total Energy Generated
* Average Monthly Generation
* Active Windmills
* Operating Units
* Best Performing Month
* Generation Share by Manufacturer

## Project Goal

To provide a centralized dashboard for monitoring renewable energy generation and supporting data-driven decision-making in windmill operations.
